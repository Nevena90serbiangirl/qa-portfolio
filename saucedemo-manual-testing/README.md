# SauceDemo Manual Testing Project

## Project Overview

This project demonstrates a structured manual testing process for [SauceDemo](https://www.saucedemo.com/), a sample e-commerce web application.

The goal is to verify the main customer journey, identify functional and usability issues, and present the work in a format that can be reviewed by recruiters and QA professionals.

## Application Under Test

- Application: SauceDemo
- Type: Web application
- Domain: E-commerce
- Test account: `standard_user`
- Password: `secret_sauce`

## Scope

The following areas are included:

- Login and validation
- Product inventory
- Product sorting
- Shopping cart
- Checkout information
- Order overview and completion
- Navigation, logout, and session behaviour
- Basic UI and usability observations

## Test Approach

- Functional testing
- Exploratory testing
- Positive and negative testing
- Boundary-value testing
- UI and usability review
- Regression testing after relevant changes
